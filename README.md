# HUB IQHA — Android APK

Репозиторий для публикации установочных файлов мобильного приложения **HUB IQHA**
для Android. Исходный код приложения здесь не хранится.

## Скачать

Готовые сборки — во вкладке [Releases](../../releases/latest):

| Файл | Что это |
|---|---|
| `hub-iqha-android-<версия>-release.apk` | подписанный release-APK для установки на телефон |
| `SHA256SUMS.txt` | контрольная сумма для проверки загрузки |

## Установка

1. Скачайте APK из последнего релиза.
2. Разрешите установку из этого источника (Android 8+ спросит при первом запуске).
3. Откройте APK и подтвердите установку.
4. Запустите приложение и сохраните API-ключ: «Настройки» → «API Ключ».

Обновления ставятся поверх предыдущей версии: подпись не меняется, данные и
настройки сохраняются. Номер версии виден в «Настройках → О программе».

## Проверка файла

```powershell
Get-FileHash .\hub-iqha-android-1.2.1-release.apk -Algorithm SHA256
```

Сравните значение с `SHA256SUMS.txt` из того же релиза.

## Требования

- Android 7.0 (API 24) и выше.
- Свободное место под установку — около 120 МБ (APK ~60 МБ).
- Для виджетов на домашнем экране: долгое нажатие на рабочем столе → «Виджеты» →
  HUB IQHA (размеры 1×1, 2×1, 2×2, 4×2).

## Подпись

Release-сборки подписаны ключом `CN=IQHA Smart Devices`
(SHA-256 `ac5347f9b7449818d602bf60a8418c383d8a9db9ec5f72290fa66bef72e301a2`).
Установка APK из этого репозитория совместима с предыдущими версиями приложения.
